# Maple Web

**Maple Web** is a desktop web browser built with Electron.

## Features

- Tabbed browsing
- Address bar
- Back and forward navigation
- Reload pages
- Bookmarks
- DuckDuckGo search
- Simple browser interface

## Installation

### 1. Install Node.js

Download and install Node.js from:

[https://nodejs.org/](https://nodejs.org/)

### 2. Download Maple Web

Clone the repository:

```bash
git clone https://github.com/GitDavin/Maple-Web.git
```

Enter the project folder:

```bash
cd Maple-Web
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start Maple Web

```bash
npm start
```

Maple Web should now open on your desktop!

## Building

To build Maple Web, run:

```bash
npm run dist
```

The generated files will appear in the `dist` folder.

## Requirements

- Node.js
- npm
- Windows, macOS, or Linux
